# Журнал

Тут то, чего нет в часах: самочувствие, контекст, болезни, поездки, стресс.
Цифры с устройства сюда не копируются, они живут в `monitoring/data/metrics.csv`.

Одна запись в день, коротко. Формат свободный, но дата в начале.

## Шаблон записи

```
## 2026-10-23

- спал: 4/5, проснулся один раз
- ноги: свежие
- контекст: поздно лёг, был на встрече
```

## Записи

```
## 2026-10-01

- пример записи, удали её
```
